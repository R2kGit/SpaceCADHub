# SpaceCADHub

SpaceCADHub verbindet den **SpaceControl SpaceController** mit
SolidCraft, Autodesk Fusion und FreeCAD. Der Hub bündelt Navigation,
Tastenbelegung und Controller-Einstellungen in einer Windows-Anwendung.

## Funktionen

- 3D-Navigation mit sechs Freiheitsgraden
- Frei belegbare Hardwaretasten und Tastenkombinationen
- Zoom über den Drehring
- Zahlenwerte per Drehring ändern – in unterstützten Feldern von SolidCraft und Fusion
- Separate Rastweiten für Skizzenlängen, Skizzenwinkel und übrige Zahlenfelder
- Individuelle CAD-Profile, LCD-Anzeige und Live-Visualisierung der Controllerbewegung

Die CAD-Anbindungen sind als separate Adapter beziehungsweise Add-ins aufgebaut.
Weitere Programme können dadurch ergänzt werden.

## Loslegen

Das Windows-Paket vollständig entpacken und `SpaceControllerCadHub.exe` starten.
Anschließend das gewünschte CAD-Profil einrichten. Fusion und FreeCAD benötigen
zusätzlich das mitgelieferte Add-in.

**Voraussetzungen:** Windows x64, .NET Framework 4.x und die originale
SpaceControl-Installation. Treiber und CAD-Programme werden nicht mitgeliefert.
Das Projekt ist für SpaceControl-Geräte gedacht, **nicht für 3Dconnexion**.
